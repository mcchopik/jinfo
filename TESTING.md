# Чек-лист тестов JInfo

Тестируем на **двух клиентах** одновременно: лицензионный (UUID v4) и offline (UUID v3).
Ниже `A` — лицензионный, `B` — offline. Отмечайте пункты после проверки.

## 1. Базовое

- [ ] Оба клиента запускаются с модом; в списке модов JInfo активен.
- [ ] `P` открывает свой профиль; клавишу можно переназначить в «Управлении».
- [ ] `/jinfo` и `/jinfo help` показывают справку.
- [ ] `Shift+ПКМ` по игроку открывает карточку; обычное взаимодействие без Shift не ломается.
- [ ] Выключение жеста в `/jinfo settings` убирает реакцию на Shift+ПКМ.

## 2. Профиль и карточка

- [ ] У игрока **нет профиля**: карточка пишет «Профиль не заполнен».
- [ ] Во время загрузки: «Загрузка...», игра не лагает (запрос в фоне).
- [ ] Наведение на голову показывает оформленный текст; ссылки в подсказке не кликабельны.
- [ ] Клик по голове открывает полный экран (аватар, ник, текст, кнопки сервисов).
- [ ] Кнопки сервисов окрашены в цвет сервиса.
- [ ] Клик по кнопке сервиса: окно «Открыть ссылку? Домен: …» с полной ссылкой,
      кнопки «Открыть»/«Отмена»; ссылка не открывается сама.
- [ ] A видит профиль B и наоборот (оба направления, лицензионный ↔ offline).
- [ ] У offline-профиля значок «не подтверждён»; у v4 — подтверждён.

## 3. Редактор в игре (`/jinfo edit`)

- [ ] Ввод многострочного текста, счётчик символов/строк.
- [ ] Кнопки цветов/стилей/сервисов вставляют корректные коды и плейсхолдеры.
- [ ] Предпросмотр совпадает с итоговым видом профиля.
- [ ] Сохранение, затем `me` показывает новый текст.
- [ ] `clear` удаляет профиль; после этого `me` → «не заполнен».

## 4. Браузерный редактор (`/jinfo web`)

- [ ] Открывается `http://127.0.0.1:<порт>/e/<токен>/`, работает предпросмотр.
- [ ] Сохранение из браузера применяется в игре.
- [ ] Закрытие вкладки с несохранёнными изменениями показывает предупреждение.
- [ ] Ошибка сети при сохранении: текст остаётся в поле.
- [ ] Закрытие игры: страница сообщает, что мод не отвечает; `stop` останавливает сервер.
- [ ] Чужой `Host`/`Origin` не может POST-ить (проверить через curl с другим Origin).

## 5. Сбои и лимиты

- [ ] Нет сети / таймаут 5 с: понятное сообщение, повтор не чаще раза в 30 с.
- [ ] Есть кэш: при ошибке показываются старые данные.
- [ ] 429 от Worker: сообщение «подожди немного».
- [ ] Сохранение чаще 1 раза в 60 с: сообщение о лимите.
- [ ] Игрок вышел с сервера с открытым меню — меню продолжает работать по UUID.
- [ ] Смена ника: профиль остаётся привязан к UUID (проверить на v4, если возможно).

## 6. Жалобы

- [ ] «Пожаловаться» на чужой профиль → «Жалоба отправлена».
- [ ] Повторная жалоба в тот же день → «Жалоба уже отправлена сегодня».
- [ ] Жалоба на себя → «Нельзя пожаловаться на себя» (через `view` невозможна, проверить API).
- [ ] Жалобы с A и B на один профиль учитываются раздельно (reporter_uuid).

## 7. Ссылки и защита текста

- [ ] `{youtube} @nick` даёт кнопку `https://youtube.com/@nick`.
- [ ] Подмена домена (`{youtube} https://evil.com`) — плейсхолдер показан текстом без кнопки.
- [ ] `javascript:`, `file:`, `http://`, `localhost`, IP, `user@host` отклоняются.
- [ ] `{link:...}` на произвольный https-домен работает, но окно помечает предупреждение.
- [ ] Сокращатели/punycode (`xn--`) помечаются предупреждением.
- [ ] Управляющие/zero-width/bidi-символы вырезаются; длинные повторы сжимаются.

## 8. Локализация и настройки

- [ ] Переключение языка ru/uk/en меняет подписи экранов и сервисов.
- [ ] Язык сохраняется после перезапуска игры.
- [ ] Состояние жеста сохраняется после перезапуска.

## 9. Сборка и релиз

- [ ] GitHub Actions зелёный на master; артефакт `jinfo` скачивается.
- [ ] Jar из артефакта ставится в чистый `mods` и запускается.
- [ ] (Только с разрешения) тег `v1.0.0` → Release с jar.
