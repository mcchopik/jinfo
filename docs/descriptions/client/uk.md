# JInfo Client

[English](en.md) | [Русский](ru.md) | [Беларуская](be.md) | **Українська**

JInfo Client — клієнтський Fabric-мод для Minecraft **26.2**, який додає короткі профілі гравців: до 500 символів, 10 рядків і 6 посилань. Профілі працюють і для ліцензійних, і для офлайн-акаунтів.

## Можливості

- **Shift + ПКМ по гравцю** — компактна картка з головою зі скіна та ніком. При наведенні на голову показується оформлений профіль.
- **Клік по голові** — повний екран профілю з 3D-скіном, що обертається, шарами, статусом, текстом, фото та кнопками сервісів.
- **Клавіша `P`** — відкриває свій профіль (змінюється в «Керуванні»).
- **Скін профілю** — автоматично, за прямим HTTPS-посиланням або з локального PNG (classic або slim), з 3D-попереднім переглядом.
- **Редактор у грі** — кольори, стилі, плейсхолдери, посилання на сервіси та живий перегляд.
- **Редактор у браузері** — локальний веб-редактор через `/jinfo web` і `/jinfo web stop`.
- **Mod Menu** — екран налаштувань JInfo доступний зі списку модів.
- **Акаунт** — нік і пароль у налаштуваннях. Сервер зберігає лише PBKDF2-хеш, авторизація Microsoft не використовується. Зайнятий нік не можна використовувати як гість. Поки увімкнено гостьовий режим, нік закріплений за ним і інші не можуть його зареєструвати, доки гість не вимкне режим.
- **Мови** — російська, білоруська, українська та англійська.

## Вимоги

- Minecraft 26.2
- Java 25
- Fabric Loader 0.20.1 або новіший
- Fabric API
- Mod Menu — за бажанням

## Встановлення

1. Встановіть Fabric Loader для Minecraft 26.2.
2. Покладіть `JInfo-Client-<version>.jar` і Fabric API у `.minecraft/mods`.
3. За бажанням встановіть Mod Menu.
4. Запустіть гру і натисніть `P` або введіть `/jinfo`.

## Команди

| Команда | Опис |
| --- | --- |
| `/jinfo help` | Показати довідку |
| `/jinfo edit` | Відкрити редактор у грі |
| `/jinfo web` | Запустити локальний веб-редактор |
| `/jinfo web stop` | Зупинити веб-редактор і закрити тунель |
| `/jinfo template <id>` | Застосувати готовий шаблон |
| `/jinfo photo <url>` | Встановити фото профілю |
| `/jinfo preview [нік]` | Переглянути профіль |
| `/jinfo set <текст>` | Задати текст профілю |
| `/jinfo me` | Показати свій профіль |
| `/jinfo view <нік>` | Показати профіль іншого гравця |
| `/jinfo clear` | Видалити свій профіль |
| `/jinfo settings` | Відкрити налаштування |
| `/jinfo update` | Перевірити оновлення |

## Приватність і безпека

Дозволені лише HTTPS-посилання. `javascript:`, `file:`, localhost, IP-адреси та посилання з логіном відхиляються. Підозрілі адреси позначаються у вікні підтвердження. Пароль акаунта не зберігається на пристрої; після входу зберігається лише токен.
