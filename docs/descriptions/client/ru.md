# JInfo Client

[English](en.md) | **Русский** | [Беларуская](be.md) | [Українська](uk.md)

JInfo Client — клиентский Fabric-мод для Minecraft **26.2**, который добавляет короткие профили игроков: до 500 символов, 10 строк и 6 ссылок. Профили работают и для лицензионных, и для офлайн-аккаунтов.

## Возможности

- **Shift + ПКМ по игроку** — компактная карточка с головой из скина и ником. При наведении на голову показывается оформленный профиль.
- **Клик по голове** — полный экран профиля с вращающимся 3D-скином, слоями, статусом, текстом, фото и кнопками сервисов.
- **Клавиша `P`** — открывает свой профиль (переназначается в «Управлении»).
- **Скин профиля** — автоматически, по прямой HTTPS-ссылке или из локального PNG (classic или slim), с 3D-предпросмотром.
- **Редактор в игре** — цвета, стили, плейсхолдеры, ссылки на сервисы и живой предпросмотр.
- **Редактор в браузере** — локальный веб-редактор через `/jinfo web` и `/jinfo web stop`.
- **Mod Menu** — экран настроек JInfo доступен из списка модов.
- **Языки** — русский, белорусский, украинский и английский.

## Требования

- Minecraft 26.2
- Java 25
- Fabric Loader 0.20.1 или новее
- Fabric API
- Mod Menu — по желанию

## Установка

1. Установите Fabric Loader для Minecraft 26.2.
2. Положите `JInfo-Client-<version>.jar` и Fabric API в `.minecraft/mods`.
3. При желании установите Mod Menu.
4. Запустите игру и нажмите `P` или введите `/jinfo`.

## Команды

| Команда | Описание |
| --- | --- |
| `/jinfo help` | Показать справку |
| `/jinfo edit` | Открыть редактор в игре |
| `/jinfo web` | Запустить локальный веб-редактор |
| `/jinfo web stop` | Остановить веб-редактор и закрыть туннель |
| `/jinfo template <id>` | Применить готовый шаблон |
| `/jinfo photo <url>` | Установить фото профиля |
| `/jinfo preview [ник]` | Посмотреть профиль |
| `/jinfo set <текст>` | Задать текст профиля |
| `/jinfo me` | Показать свой профиль |
| `/jinfo view <ник>` | Показать профиль другого игрока |
| `/jinfo clear` | Удалить свой профиль |
| `/jinfo settings` | Открыть настройки |
| `/jinfo update` | Проверить обновления |

## Плейсхолдеры профиля

`{youtube}`, `{twitch}`, `{discord}`, `{telegram}`, `{tiktok}`, `{instagram}`, `{x}`, `{github}`, `{steam}`, `{vk}`, `{reddit}`, `{kick}`, `{boosty}`, `{donationalerts}`, `{modrinth}` — далее `@ник` или HTTPS-ссылка.

Универсальная ссылка: `{link:Название} https://example.com`. Фото: `{photo} https://example.com/photo.png`.

Цвета: `&0`–`&f`, `&l`, `&o`, `&n`, `&m`, `&r`, hex `&#RRGGBB`.

## Приватность и безопасность

Разрешены только HTTPS-ссылки. `javascript:`, `file:`, localhost, IP-адреса и ссылки с логином отклоняются. Подозрительные адреса помечаются в окне подтверждения.
