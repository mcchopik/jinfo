# JInfo Client

[English](en.md) | [Русский](ru.md) | **Беларуская** | [Українська](uk.md)

JInfo Client — кліенцкі Fabric-мод для Minecraft **26.2**, які дадае кароткія профілі гульцоў: да 500 сімвалаў, 10 радкоў і 6 спасылак. Профілі працуюць і для ліцэнзійных, і для афлайн-акаўнтаў.

## Магчымасці

- **Shift + ПКМ па гульцу** — кампактная картка з галавой са скіна і нікам. Пры навядзенні на галаву паказваецца аформлены профіль.
- **Клік па галаве** — поўны экран профілю з 3D-скінам, які круціцца, пластамі, статусам, тэкстам, фота і кнопкамі сэрвісаў.
- **Клавіша `P`** — адкрывае свой профіль (змяняецца ў «Кіраванні»).
- **Скін профілю** — аўтаматычна, па прамой HTTPS-спасылцы або з лакальнага PNG (classic або slim), з 3D-прадпраглядам.
- **Рэдактар у гульні** — колеры, стылі, плэйсхолдары, спасылкі на сэрвісы і жывы прадпрагляд.
- **Рэдактар у браўзеры** — лакальны вэб-рэдактар праз `/jinfo web` і `/jinfo web stop`.
- **Mod Menu** — экран налад JInfo даступны са спіса модаў.
- **Мовы** — руская, беларуская, украінская і англійская.

## Патрабаванні

- Minecraft 26.2
- Java 25
- Fabric Loader 0.20.1 або навейшы
- Fabric API
- Mod Menu — па жаданні

## Усталёўка

1. Усталюйце Fabric Loader для Minecraft 26.2.
2. Пакладзіце `JInfo-Client-<version>.jar` і Fabric API у `.minecraft/mods`.
3. Пры жаданні ўсталюйце Mod Menu.
4. Запусціце гульню і націсніце `P` або ўвядзіце `/jinfo`.

## Каманды

| Каманда | Апісанне |
| --- | --- |
| `/jinfo help` | Паказаць даведку |
| `/jinfo edit` | Адкрыць рэдактар у гульні |
| `/jinfo web` | Запусціць лакальны вэб-рэдактар |
| `/jinfo web stop` | Спыніць вэб-рэдактар і закрыць тунэль |
| `/jinfo template <id>` | Ужыць гатовы шаблон |
| `/jinfo photo <url>` | Устанавіць фота профілю |
| `/jinfo preview [нік]` | Паглядзець профіль |
| `/jinfo set <тэкст>` | Задаць тэкст профілю |
| `/jinfo me` | Паказаць свой профіль |
| `/jinfo view <нік>` | Паказаць профіль іншага гульца |
| `/jinfo clear` | Выдаліць свой профіль |
| `/jinfo settings` | Адкрыць налады |
| `/jinfo update` | Праверыць абнаўленні |

## Прыватнасць і бяспека

Дазволены толькі HTTPS-спасылкі. `javascript:`, `file:`, localhost, IP-адрасы і спасылкі з лагінам адхіляюцца. Падазроныя адрасы пазначаюцца ў акне пацверджання.
